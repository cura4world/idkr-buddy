# 단어장 검토 기록 (2026-11)

S43 단어장 재분류·검토 때 공개 단어장(옛 01~29, 지금 번호로 02~34 중 기존 29권)을 한 줄씩 읽고 고친 내역입니다.
파일 이름은 **지금(새) 번호**로 적었습니다. 성경과 신앙(35~41)은 이번 검토 대상이 아니라 번호만 바뀌었습니다.

종류 설명

- **철자**: KBBI 표준 표기로 고침 (예: coklat → cokelat, lembab → lembap, siapapun → siapa pun). 표제어가 바뀐 경우 예문도 함께 고쳐 칸이 둘로 셈.
- **표제어**: 낱말 자체가 잘못 잡혀 있어 바꿈 (예: menjabat → berjabat tangan, menyiram api → memadamkan).
- **뜻**: 한국어 뜻이 틀리거나 빠진 것 (예: RT·RW 통·반이 뒤바뀜, singkong 은 고구마가 아니라 카사바).
- **예문**: 비문·부자연스러움·사실 오류·표제어가 예문에 없음 (예: 인도네시아 새 학년은 1월이 아니라 7월).
- **번역**: 예문뜻이 어색하거나 원문과 어긋남. 인도네시아어 예문은 그대로.
- **중복예문**: 다른 표제어와 예문이 같거나 거의 같아 하나를 새로 씀.
- **문장부호**: 두 절이 쉼표 없이 붙어 읽기 어려운 것만 고침. 문장 앞 접속 표현 뒤 쉼표(PUEBI)는 일부러 일괄로 고치지 않았습니다.
- **교체**: 표제어를 다른 단어로 바꿈 (비표준형·대소문자만 다른 겹침).

## 손대지 않은 것 (확인 부탁)

- **동음이의어 11쌍**은 공개 단어장 사이에 그대로 둡니다 (뜻이 달라 일부러 둔 것, `scripts/check-wordlist.js` 3-1항): buah·biji·gelas·piring(수분류사/명사), menarik, tahu, baru, menguap, resep, bunga, tablet.
- **공개 단어장 예문 속 기독교 표현**(Tuhan·Yesus·Roh Kudus·gereja·jemaat 등)은 문장이 바르면 그대로 두었습니다. 공개판에 그대로 둘지 사용자 결정이 필요합니다 (보고서 참고).
- **흔히 쓰는 비표준 표기**: maag(KBBI mag), tipes(KBBI tifus), rice cooker, zebra cross, flashdisk 는 실제 생활 표기라 두었습니다.
