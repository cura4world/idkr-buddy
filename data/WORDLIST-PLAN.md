# 공용 단어장 계획

목표 3,056단어 / 36권. 주제별 분류이며 품사는 기준이 아니다.
작업 이력과 원칙은 `DECISIONS.md`, 코딩 규칙은 `CLAUDE.md` 참고.

## 1. 원칙

- **주제 우선, 품사 무시.** `berdoa`(기도하다)는 동사지만 `34 기도·찬양`으로 간다.
- **빈도 우선.** 채울 때는 인도네시아어 고빈도 어휘부터 넣는다. 희귀어로 칸을 메우지 않는다.
- **접사 가족을 활용한다.** 인도네시아어는 어근+접사 구조라 `ajar → belajar / mengajar / pelajaran / pengajar / pelajar`처럼 하나에서 여럿이 나온다. 어근 가족이 3개 이상 모이면 `08 접사 가족`에 연속된 줄로 모은다.
- **기독교 어휘는 넉넉히.** 사용자가 목회에 쓰므로 30~36번에 550단어를 배정했다.
- **`08 접사 가족`의 역할.** 모든 어근 가족을 모으는 곳이 아니라, 접사 규칙(`me-`, `pe-`, `-an`, `ter-`, `ke-...-an`)이 뜻을 어떻게 바꾸는지 보여주는 **대표 예시 모음**이다. `menulis`는 07, `penulis`는 19에 있어도 된다 — 주제별 분류가 우선이고, 08은 문법 감각을 익히는 보조 단어장이다.
- **같은 단어장 안에 같은 표제어를 두지 않는다.** 단어 ID가 `shared_{categoryId}_{word}`라 충돌한다. 동음이의어는 서로 다른 단어장으로 나눈다.

## 3. CSV 형식 (반드시 지킬 것)

- 헤더 없이 4열: `인니어,한국어,예문,예문뜻`
- BOM 없는 UTF-8, 줄바꿈 LF, 마지막 줄도 개행으로 끝낼 것
- 쉼표나 큰따옴표가 든 필드는 큰따옴표로 감싼다. 필드 안 큰따옴표는 `""`로 이스케이프
  - 예: `lupa,잊다,Maaf saya lupa membawa buku itu.,"미안해요, 그 책 가져오는 걸 잊었어요."`
- 예문은 일상적이고 자연스러운 한 문장. 예문뜻은 그 문장의 한국어 번역
- 파일명이 곧 앱에 표시되는 단어장 이름이다. 숫자 두 자리 접두사를 반드시 유지할 것

## 4. 검증

```
node scripts/check-wordlist.js
node scripts/csv-to-seed.js
npm run build
```

`check-wordlist.js`에서 **중복(뜻이 같음) 0건 / 형식오류 0건 / BOM 0개 / 쉼표 병합 행 0건**이어야 한다.
동음이의어 항목은 의도된 것이라 0건이 아니어도 된다.
