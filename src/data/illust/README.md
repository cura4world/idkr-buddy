# 단어장 색연필 그림 (S50)

기본 단어장 단어 카드에 들어가는 작은 그림입니다. 단어마다 **예문 한 장면**(또는 대표 그림 하나)을
색연필 화풍 SVG 로 그립니다. 완벽하게 설명하지 않아도 됩니다 — 심플하고 비정형이면 충분합니다.
카드·퀴즈 화면에는 넣지 않고, 단어장 안 단어 카드에만 들어갑니다.

## 파일

- 단어장 한 권 = 파일 하나: `illust-<key>.json` (이 폴더).
- `<key>` 는 영문 소문자·숫자·하이픈. 단어장 이름(번호 뺀 것)과의 연결은
  `src/lib/illust.ts` 의 `ILLUST_BOOK_KEYS` 에 한 줄 더합니다. 예: `"동물": "hewan"`.
- 단어장 번호(23 → 28 등)가 바뀌어도 파일·키는 그대로입니다. 그림은 **인도네시아어 표제어**로 찾습니다.
- 빌드하면 파일마다 따로 떨어진 자원이 되고, 그 단어장을 열 때만 받아 폰에 남깁니다
  (설치 때 한꺼번에 받지 않음 — `vite.config.ts` 의 `globIgnores`·`runtimeCaching`).
- 그림이 없는 단어는 아무것도 그리지 않습니다(자리 표시 없음). 일부 단어만 그려 두어도 됩니다.

```json
{
 "book": "동물",
 "scenes": {
  "kucing": { "vb": "0 0 120 72", "h": 66, "r": 52, "t": -12, "art": "<rect .../>..." },
  "di atas": { "vb": "0 0 120 72", "h": 64, "r": 60, "t": -12, "line": false, "art": "..." }
 }
}
```

| 필드 | 뜻 | 기본 |
|---|---|---|
| 키 | CSV 첫 열 표제어와 글자 그대로 같게 (`kupu-kupu`, `di atas`) | — |
| `vb` | viewBox. 기본 장면은 `0 0 120 72` (5:3). 한 가지만 그린 그림은 `0 0 64 72`, `0 0 80 64`, `0 0 90 56` 처럼 좁게 | — |
| `h` | 화면 높이 px. **56~70** (단어 두 줄 높이를 살짝 넘는 정도) | — |
| `r` | 단어 줄 오른쪽 끝(스피커 38px 포함)에서 그림 오른쪽 끝까지 px. **50~105**. 스피커와 겹치지 않게 50 이상 | 56 |
| `t` | 단어 줄 위에서 그림 위까지 px. **-10~-14** (카드 위 여백으로 살짝 올라감) | -12 |
| `line` | 색연필 윤곽선 겹치기. 사물·동물은 켬, 사람 여럿·기호가 많은 장면은 `false` 가 깔끔 | true |
| `art` | `<svg>` 안쪽 도형만. 한 번만 적습니다 — 칠 한 겹과 윤곽선 한 겹은 화면이 겹쳐 그립니다 | — |

### 화면이 자리를 고치는 방식 (QA Q02)

`r`·`t`·`h` 는 **원하는 자리**입니다. 화면(`WordIllust.tsx` → `src/lib/illustFit.ts`)은 그 카드의
단어·뜻 글자를 줄마다 실제 폭으로 재고 스피커 버튼을 재서, 그림 상자(viewBox 전체)를 글자와 버튼 사이
빈칸에만 놓습니다. 뜻이 길거나 글자를 키우거나 화면이 좁아 그 자리에 안 들어가면
① 오른쪽(스피커 쪽)·위아래로 조금 옮기고 ② 최소 높이 40px 까지 줄이고 ③ 그래도 안 되면 그 카드에서는 그리지 않습니다.
위로는 카드 위 끝에서 2px 까지, 아래로는 예문 상자 바로 위까지만 씁니다. 카드 크기는 바뀌지 않습니다.
그래서 `vb` 의 좌우 빈 여백은 그만큼 그림을 작게 만듭니다 — 그림을 viewBox 에 꽉 차게 그릴수록 크게 보입니다.

## 그리는 규칙

- **자리**: 단어 글자와 스피커 사이 빈칸. 왼쪽 글자 아래로 깔려도 되지만(글자가 위 층),
  예문 상자 위로 내려오지 않게 `vb` 아래쪽 여백을 남깁니다. 카드 크기를 늘리지 않습니다.
- **도형**: `rect`·`circle`·`ellipse`·`path`·`polygon` 만. `<g transform>` 으로 묶어 옮기기 가능.
  `<text>`·`<image>`·`<use>`·외부 참조·`<script>`·`style` 속성·`id` 는 쓰지 않습니다.
- **필터**: `filter` 를 직접 쓰지 않습니다. 화면이 `url(#pcFill)`(칠: 가장자리 흔들림 + 종이 결)과
  `url(#pcLine)`(윤곽선: 진한 갈색 `#6B5444` 1.1px, 반투명 0.5)을 씌웁니다.
- **선**: 굵기 1.6~5, 끝은 `stroke-linecap="round"`. 점선 경로는 `stroke-dasharray="2 4"`.
- **팔레트** (밝고 차분한 색연필 톤, 진한 원색 금지)

| 쓰임 | 색 |
|---|---|
| 눈·입 선 | `#2E2A27` |
| 피부 / 머리 / 바지 | `#F3D2B5` / `#5B4636` / `#4A5A6A` |
| 하늘·물·소파 | `#9CCBDA` `#7FB7C9` `#B7DCE7` `#CFE6EE` |
| 풀·나뭇잎 | `#8DC07A` `#7DB36A` `#9CCB88` `#C9D9A8`(땅 선) |
| 나무·가구 | `#C99A6B` `#A97E52` `#9A7350` `#8A6A50` |
| 따뜻한 강조 | `#F2A65A` `#F0A070` `#F5C26B` `#F4C542` |
| 분홍·보라 | `#F2A7C3` `#F29BB0` `#B98BE0` `#B9A7E0` |
| 빨강(금지·화남 표시) | `#E07A6A` `#E07A7A` `#EF8F8F` |
| 회색(코끼리·말풍선 테두리) | `#A9B4BE` `#97A3AE` `#B7C3C9` `#9BB3BF` |
| 흰 바탕 조각 | `#FFFFFF` `#FFF8EC` |

- **크기**: 장면 하나 `art` 1~2.5KB (파일 안 한 단어 약 1.5~3KB). 사람·동물은 몇 개의 도형으로 —
  사람 = 머리 원 + 머리카락 path + 몸 rect(rx 6) + 팔다리 선. 표정은 눈 점 두 개 + 입 선 하나.
- **장면 고르기**: 예문의 핵심 한 순간(소파 위에서 자는 고양이, 책상 위 책). 추상어(접속사 등)는
  인물 두셋의 표정·몸짓 + 기호(?, ✕, 화살표, 말풍선)로 대비를 보여 줍니다.

## 처음 들어간 그림

시안(K1 동물, K4 전치사·접속사)에 그린 12장면을 그대로 옮겼습니다.

- `illust-hewan.json` — kucing, anjing, gajah, monyet, burung, kupu-kupu
- `illust-preposisi.json` — di atas, di sebelah, juga, malah, padahal, bahkan (`line: false`)

## 확인

1. JSON 형식이 맞는지: `node -e "JSON.parse(require('fs').readFileSync('src/data/illust/illust-<key>.json','utf8'))"`
2. 키가 CSV 표제어와 같은지(없는 키는 화면에 안 나올 뿐 오류는 아님).
3. `npm run build` 뒤 `dist/assets/illust-<key>-*.json` 이 생겼는지.
4. 폰에서 그 단어장을 열어 그림이 단어·스피커와 겹치지 않는지 눈으로 봅니다(겹치지 않게 하는 것은 화면이 하지만,
   너무 작아지거나 숨겨지는 단어가 많으면 `h`·`r` 이나 viewBox 여백을 고칩니다).
