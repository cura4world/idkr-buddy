# 01. 프로젝트 브리프 — Kata kata 공개판 (Google Play)

작성: 2026-11-10 · 단계: BMAD 1 (Analyst)

## 한 줄

지금 세 분이 쓰는 Kata kata에서 **성경·기독교 콘텐츠를 뺀 공개판**을 Google Play에 올린다.
같은 웹 앱을 쓰되, 스토어 앱에서는 자동으로 공개판이 되고 Google 로그인·구독·사용량 한도가 붙는다.

## 세 가지 판

| 판 | 누가 | 어떻게 설치 | 보이는 것 |
|---|---|---|---|
| 관리자판 | Arga | 기존 APK (`io.github.cura4world.twa`) | 전부 (설교 포함) |
| 회원판 | 지인 | 기존 APK + 회원키 | 설교만 빠짐 |
| **공개판** | 누구나 | **Google Play (`app.naruve.katakata`)** | 성경·묵상·기도·설교·일대일·뉴스·기독교 이해 빠짐 |

관리자판·회원판은 그대로 둔다. 이번 작업은 공개판만 새로 만든다.

## 대상과 범위 (2026-11-10 결정)

- 대상: 인도네시아어를 배우는 한국어 사용자. **화면은 한국어, 출시 국가는 전 세계**
- 포함 메뉴: 사전, 단어장(내 단어장·단어장 폴더), 오늘의 문장(성경 말씀 종류 제외), 이야기, 인도네시아 이해·지도(기독교 항목 제외), 회화집, 단어게임
- 제외: 뉴스, 성경 읽기, 묵상, 기도문, 설교문, 일대일 성경공부, 인도네시아 이해의 기독교 항목
- 로그인: **Google 로그인 필수** (처음 실행할 때)
- 개발자 계정: 조직(사업자) 계정 — 비공개 테스트 12명·14일 요건 없음

## 요금 (확정 아님 — 항목별 재논의)

- **2026-11-14 결정**: 월 3,900원 / 연 34,800원(월 2,900원 꼴), 7일 무료 체험 (처음 적었던 잠정 연간 가격은 폐기)
- 단어 AI(사전 풀이)는 무료 사용자도 **사실상 무제한** (남용 방지 상한만 둔다)
- 소리 읽기는 Gemini 음성으로 하고 횟수 제한 또는 일부 기능 제외 — **재논의**
- 폰 내장 음성은 쓰지 않는다 (품질이 낮아 앱 이미지를 해친다)
- Plus 혜택 구성 — **재논의**

그래서 이번 구현은 금액과 한도를 **서버 설정값**으로만 두고, 화면 문구는 한 곳에 모아 나중에 바꾸기 쉽게 한다.

## 출시를 막는 것 (2026-11-09 점검)

1. 공개판은 AI가 꺼져 있다 — 키도 회원키도 없으면 `NO_API_KEY`
2. Play 결제가 없다 (웹뷰 안에서는 불가 → 네이티브 필요)
3. 타깃 API 34 → 신규 앱은 36 필요 (2026-08-31부터)
4. APK만 만든다 → AAB 필요
5. APK 파일 저장이 안드로이드 10 이상에서 실패
6. 개인정보처리방침·데이터 보안·계정 삭제·AI 신고 기능 없음
