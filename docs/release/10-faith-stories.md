# 10. 기독교 메뉴 공개판 디자인 — 관리자·Special Member 용 (2026-11-12 밤)

작성: 2026-11-12 · 단계: BMAD 4 (SM) → 5 (Dev) → QA · 바탕: 사용자 요청(2026-11-12 22:42),
`08-polish-stories.md` 의 공통 규칙과 지금까지 다듬은 화면(이야기 ST1~ST5, 회화집 PC1~PC4, 인도네시아 이해 IN1).

**배경:** 공개판(스토어 앱)은 기독교 콘텐츠를 모두 뺐다(FR2). 사용자는 공개판 앱 하나로 관리자·Special Member 도
쓰게 할 계획이라(결정 문서 "계획 변경 구상"), **관리자·Special Member 에게는 기독교 메뉴를 보여 준다.**
이 화면들은 아직 예전 디자인(진한 장미색·하늘색·초록 버튼)이라, 지금까지 다듬은 화면의 패턴으로 먼저 맞춘다.
사용자가 폰에서 보고 고칠 곳을 다시 요청한다(선작업).

상태: ✅ 완료 · 🟡 부분 · ⬜ 아직 · 🔍 사용자 검토 대기

## 범위

- 무료·체험·Plus 사용자 화면은 바뀌지 않는다(메뉴가 보이지 않고, 주소로 들어와도 홈으로).
- 관리자판·회원판(`main`)의 기능은 없애지 않는다. 디자인만 같은 패턴으로 바뀐다(병합 뒤 관리자판도 같은 모양).
- **기능(서버·키)은 이번 범위가 아니다.** 묵상·기도문은 Claude 키 또는 회원키, 성경은 회원키로 받은 역본,
  설교문은 설교문 서버 설정이 필요하다. 공개판에서 이 연결을 어떻게 줄지는 "회원키를 공개판 설정에서 넣는" 결정 뒤에 한다.

## QA 기록 (S70)

- 360px 화면 캡처: 홈(무료·Plus·Special·관리자), 묵상 목록·카드, 기도 목록·주기도문·만들기, 뉴스 첫면·기사, 성경, 일대일, 설교, 기독교 이해, 회원키 관리.
- 등급 검사(미리보기 등급 전환): 무료·Plus — 기독교 메뉴 없음, `/devotion`·`/members` 주소는 홈으로. Special — 말씀과 기도·뉴스·기독교 이해 있음, 설교 없음.
  관리자 — 모두 있음. 단어 수 무료·Plus 3,005 / staff 3,555, 대화 수 86 / 94.
- 작업 안 본 검토자 1회 — 고친 것: 설교 주소도 관리자만(`need="admin"`), 홈 단어 수를 한 번만 세기(useMemo, 검색 입력마다 400KB 파싱 반복하던 것),
  기도문 인니어 글자 크기 한 칸 보정(content-bump 를 뺀 만큼), 꼬리표 말줄임, 기도문 만들기 버튼이 입력 중 키보드 위에 떠 있던 것(`--kata-tabbar-float`).
  그대로 둔 것: 재생 중 듣기 버튼 뒤의 연한 알약 — 이야기 카드와 같은 덮어쓰기 방식이라 같은 모양(PlayButton 수정 금지).
