## 검토 반영 (2026-11-10, 작업을 보지 않은 별도 검토자)

| 지적 | 처리 |
|---|---|
| 한도를 호출 뒤에 세어, 동시에 몰아 보내면 한도 초과 | ✅ 부르기 전에 한 칸 선점, 실패·예외면 환불. KV 특성상 아주 짧은 동시 요청은 남음 → 사용자 늘면 Durable Object (05 문서 10절) |
| 서버가 아무 Gemini 설정이나 통과 (범용 대리 창구) | ✅ `sanitizeAiBody` 허용 목록: 글 본문 + 음성 지시·음성 설정 + JSON 응답 설정만, 출력 상한·후보 1개 강제, 글자 수 상한 |
| 기다리는 쪽 없는 구매 알림을 버림 → 확인 안 된 구매가 사흘 뒤 환불 | ✅ 버리지 않고 서버 검증. 앱 시작 때 조용히 구매 재확인 (`autoRestoreOnce`) |
| 계정 삭제 때 마지막 구매 토큰만 풀림 | ✅ 계정별 토큰 목록(`uptok:`)을 두고 전부 해제 |
| 삭제 후 같은 Google 계정 재가입 시 옛 세션 부활 | ✅ 세션 생성 시각 < 계정 생성 시각이면 거절 |
| Play 재확인 실패 시 요청마다 다시 호출 | ✅ 실패해도 확인 시각 기록(한 시간 뒤 재시도) |
| 신고 목록이 오래된 것부터 | ✅ 시각을 거꾸로 센 키로 최신순 |
| 숨김 판단이 `getEdition()`/`isStoreApp()` 섞임 → 브라우저 사용자 뉴스 사라짐 | ✅ 모두 `isStoreApp()` 로 통일 |
| 홈 화면에서 뒤로가기 후 돌아오면 뒤로가기 먹통 | ✅ `moveTaskToBack(true)`, 콜백 유지 |
| 스토어 음성이 한국어 글도 "인도네시아어" 지시로 읽음 | ⏸ 음성 재논의 때 결정 (05 문서 10절) |
| 로그인 nonce 선택 사항 | ⏸ Google ID 토큰 자체가 서명·만료·대상 확인됨. 필요 시 추가 |
| API 28 이하에서 백업 파일이 앱 전용 폴더로 저장 | ⏸ 남겨 둠 (Android 9 이하 비중이 작음). 필요하면 저장 위치 안내를 추가 |

상태는 작업이 끝날 때 실제 결과로 고친다.
