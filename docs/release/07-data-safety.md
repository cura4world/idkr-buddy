# 07. 데이터 보안(Data safety) 답안

작성: 2026-11-10 · 고침: 2026-11-14(출시 전 점검 P-06·P-07·P-14 — 프로필 사진 주소, 보관 기간, 신고에 담기는 것, AI 입력·출력 처리, 마이크)
Play Console → 앱 콘텐츠 → 데이터 보안
근거: `workers/kata-public/worker.js`(서버가 실제로 저장하는 것)와 `public/privacy.html`.
코드가 바뀌면 이 답안도 같이 고칩니다.

## 첫 질문들

| 질문 | 답 | 이유 |
|---|---|---|
| 필수 사용자 데이터 유형을 수집하거나 공유하나요? | **예** | Google 로그인 정보, 구독 정보 |
| 모든 사용자 데이터가 전송 중 암호화되나요? | **예** | 모든 통신 HTTPS |
| 사용자가 데이터 삭제를 요청할 수 있나요? | **예** | 앱의 내 정보 탭 맨 아래 "계정 삭제" + 계정 삭제 안내 페이지(`public/delete-account.html` 이 정본) |
| 계정 생성 방법 | **OAuth(Google 로그인)** | |
| 계정 삭제 웹 주소 | `https://naruve.app/apps/kata-kata/delete/` | |

## 수집하는 데이터 (공유는 모두 "아니요")

Play 기준에서 **서비스 제공업체(Google·Cloudflare)에 처리를 맡기는 것은 "공유"가 아닙니다.** 광고·분석 회사에 넘기는 것이 없으므로 공유는 모두 "아니요"입니다.

| 데이터 유형 | 수집 | 필수/선택 | 목적 | 비고 |
|---|---|---|---|---|
| 개인 정보 › **이메일 주소** | 예 | 필수 | 계정 관리, 앱 기능 | Google 로그인 |
| 개인 정보 › **이름** | 예 | 필수 | 계정 관리 | Google 프로필 이름 |
| 개인 정보 › **사용자 ID** | 예 | 필수 | 계정 관리, 사기 방지 | Google 계정 식별자 |
| 개인 정보 › **기타 정보** | 예 | 필수 | 계정 관리 | **Google 프로필 사진 주소**(사진 파일이 아니라 주소 글자). 서버의 계정 정보에 함께 저장되고 앱의 내 정보 탭에 얼굴 그림으로 보임. Play 양식에 "프로필 사진 주소" 칸이 따로 없어 "기타 정보"로 표시 |
| 금융 정보 › **구매 기록** | 예 | 선택 | 앱 기능, 사기 방지 | 구독 상품·만료 시각·구매 토큰 (결제 수단은 받지 않음) |
| 앱 활동 › **앱 상호작용** | 예 | 필수 | 앱 기능(이용 한도), 사기 방지 | 기능 사용 횟수 — 날짜별 3일, 월별 최대 40일, 무료 체험 합계 최대 400일 보관. 날짜별 기록에는 그날 들은 이야기·회화의 구분값(재생 키)도 들어감 |
| 앱 활동 › **기타 사용자 제작 콘텐츠** | 예 | 선택 | 앱 기능(품질 개선) | 이용자가 **"풀이가 이상합니다"를 눌러 보낸 신고**: 사유(고정 3종), 그때의 입력(검색어·주제, 500자까지), **AI 가 만든 결과(2,000자까지)**. 180일 보관, 계정 삭제 시 계정 연결을 지움 |
| 앱 활동 › **인앱 검색 기록** | 예 (**일시적 처리**) | 필수 | 앱 기능 | 사전 검색어·이야기/회화 만들기에 넣은 글·읽을 본문은 서버를 거쳐 Google(Gemini)로 전달되어 결과를 만드는 데만 쓰이고 저장하지 않음. Play 양식에서 "일시적 처리"는 **수집으로 표시한 뒤 고르는 칸**이라 "수집: 예 → 일시적으로 처리됨"으로 답함. AI 가 만든 결과(출력)도 서버를 지나가기만 하고 저장하지 않음(신고한 경우만 위 줄대로 저장) |

## 수집하지 않는 것으로 답하는 것 (판단 근거)

| 데이터 | 답 | 근거 |
|---|---|---|
| 사진·동영상·파일 | 아니요 | 백업 파일은 기기에만 저장 |
| 오디오(음성 검색) | 아니요 | 마이크는 검색창의 마이크 단추를 누를 때만 씀. 소리는 기기의 음성 인식 서비스(Web Speech — 기기 설정에 따라 Google 등)가 글자로 바꾸고, 우리 앱 코드는 소리를 받지도 서버로 보내지도 않음(코드에 녹음·전송 없음: `Dictionary.tsx`·`Index.tsx` 의 `SpeechRecognition` 만 사용). 개인정보처리방침 1절에 마이크 문단 있음. **보수적으로 가려면** "오디오 › 음성 또는 소리 녹음: 수집, 선택, 일시적 처리"로 답해도 됨 |
| 위치·연락처·기기 ID | 아니요 | 쓰지 않음 |
| 단어장·학습 기록 | 아니요 | 기기에만 저장, 서버로 보내지 않음 (공개판에는 서버 백업 없음) |
| (참고) 글꼴 | 해당 없음 | 글꼴(Lora·Gowun Dodum·Pretendard)은 앱 안에 들어 있음 — Google Fonts·jsdelivr 등 외부 글꼴 서버에 요청하지 않음 (2026-11-11 QA Q14, `src/fonts.ts`). 외부 요청으로 적을 것 없음 |

※ 검색어·입력 글은 2026-11-14 부터 위 "수집하는 데이터" 표에 "수집 + 일시적 처리"로 옮겼습니다(예전에는 "수집 안 함"으로 적었으나, Play 양식의 일시적 처리는 수집으로 표시한 뒤 고르는 칸입니다).
※ 확인하지 못한 것: 서버 뒤의 중계(Cloud Run)와 Google Gemini 쪽이 입력을 얼마나 보관하는지는 이 저장소의 코드로 알 수 없습니다. Google 의 유료 API 약관(입력을 모델 학습에 쓰지 않음)을 근거로 "일시적 처리"로 답합니다.

## 보안 관행

- 전송 중 암호화: 예
- 삭제 요청: 예 (앱 안 + 웹)
- 독립 보안 검토: 아니요 (해당 없으면 체크하지 않음)
