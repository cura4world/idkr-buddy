# 옵션 창(시트·대화상자) 디자인 통일 — 설계 보고 (2026-11-24)

> 승인 전에는 앱 코드를 바꾸지 않는다. 시안 그림 4장(412px·글자 100%, 왼쪽 = 지금, 오른쪽 = 시안)은
> 저장소 밖에서 만들어 대화로 보냈다(그림 파일을 저장소에 넣으면 보안 게이트의 "못 읽는 파일"이 늘어서).
> 시안의 "후"는 실제 앱 화면 위에 새 틀의 HTML 을 덮어 찍은 것이고, 글·목록은 "전" 창에서 그대로 읽어 넣었다.

### 2-4. 더 다듬을 점(제안)

- **머리 아이콘 규칙**: 입력·고르기는 청록, 위험 확인은 빨강, Plus 는 금색, 그 밖 안내는 청록. 아이콘은 그 창이 하는 일 하나(연필·목록·휴지통·자물쇠).
- **빈 상태 문구**(예: 담을 단어장이 없음): 본문 가운데 작은 아이콘 + 한 줄(font-gothic 0.8125rem #9AA1A6) + 필요하면 보조 단추 하나.
- **길게 스크롤될 때**: 머리·바닥은 고정, 가운데가 움직이면 바닥 위에 옅은 그림자.
- **뒤로가기 빈틈 4개를 함께 고침**(1절 끝) — 틀이 useBackClose 를 품기 때문.
- **대상 밖으로 둘 것**: 전체 화면 덮개 4개(음성 듣는 중·화면 잠금 2·사진 크게 보기 — 창이 아니라 상태 화면), 성경 책·장 말풍선(BibleDial — 위치가 버튼에 붙는 형태라 따로), 설정(SettingsDialog — 관리자용 큰 설정 페이지, 마지막 묶음에서 겉 틀만). BiblePicker 는 쓰지 않는 파일이라 지우기를 제안(별건).
