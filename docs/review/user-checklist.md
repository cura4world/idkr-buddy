## (가) 폰에서 확인할 것 — 미리보기 APK

받는 법: GitHub 저장소 → Actions → **Build Preview APK (공개판 미리보기)** 의 가장 새 실행 → 맨 아래 Artifacts `kata-kata-preview-apk`.
오른쪽 아래 "미리보기 · 등급" 알약으로 등급을 바꿔 가며 봅니다. **무료 → Plus → Special(또는 관리자)** 순서가 편합니다.

미리보기 APK 에서는 **볼 수 없는 것**: 로그인 화면, 결제, AI 신고 단추("AI가 만든 내용입니다 · 풀이가 이상합니다"), 로그아웃·계정 삭제, 인터넷 없이 처음 열 때의 안내. 이것들은 (나)의 스토어 앱 내부 테스트에서 봅니다.

### 4. 1·2차에서 남아 있던 폰 확인

- 구독 화면(무료): 연간 카드에 "연 34,800원" 크게, "(월 2,900원)" 작게. 버튼 아래 첫 줄 "해지 전까지 매년 자동으로 결제됩니다."
- 내 정보 → 백업·새 폰으로 옮기기 → 백업 파일 저장 → "마지막 백업 (오늘 날짜)". 그 파일을 "백업 파일 불러오기"로 다시 넣었을 때 단어장·이야기·만든 회화가 돌아오는지.
- 단어 추가 창의 단어장 고르기 칸에 성경과 신앙 단어장 이름이 보이지 않는지(무료·Plus).

2부에서 화면 글자를 많이 고쳤습니다. 바뀐 곳 목록은 `prelaunch-2026-11-13-followup.md` 의 "5-1 앱 UI 문구" 절에, 화면별로 볼 것은 그 절의 "3. 폰에서 눈으로 확인할 화면"에 있습니다(홈·사전·이야기·회화집·게임·단어장·구독 화면·내 정보·훈장 창·지도). 큰 것만 적으면:

- 게임 이름 "빠른 짝짓기" → "빠른 짝 맞추기"
- 회화집 안의 묶음은 "주제", 한 편은 "대화"(만들기 버튼 "대화 만들기")

- 다시 시도 안내는 "잠시 뒤 다시 시도하세요" 한 가지
