### 읽고 문제없다고 본 것

- **인증**: Google ID 토큰의 서명·발급자·대상·만료를 확인합니다. 세션 토큰은 무작위 32바이트이고 서버에는 해시만 저장됩니다. 계정을 지운 뒤 같은 계정으로 다시 가입해도 옛 세션은 살아나지 않습니다.
- **등급**: 앱이 보낸 등급을 믿지 않습니다. 등급은 서버가 Play 답과 관리자 기록에서만 계산합니다. 잠긴 기능은 서버가 403 으로 거절합니다.
- **결제**: 구매 토큰은 한 계정에만 묶이고, 다른 계정의 구매·다른 상품·없는 토큰을 거절합니다. Play 가 답하지 못할 때 무료로 떨어뜨리지도, 영원히 유료로 두지도 않습니다.
- **관리자 경로**: 전부 같은 관리자 열쇠 확인 뒤에 있고 비교는 길이가 같을 때 시간 차가 나지 않게 합니다. 신고 목록은 계정 번호를 가려서 줍니다.
- **AI 대리 호출**: 허용한 모델과 허용한 요청 모양만 통과합니다(도구 사용·시스템 지시문 등은 버림). 글자 수·출력 길이에 상한이 있습니다.
- **앱의 저장 값**: 세션 토큰은 앱 전용 저장소(localStorage)에 있습니다. 스토어 앱은 폰 백업을 끄고(`allowBackup=false`) 평문 통신을 막습니다. 앱 묶음에 비밀값이 없습니다. 바깥 페이지는 앱 안에서 열지 않고 밖으로 넘깁니다(네이티브 통로가 바깥 페이지에 노출되지 않음).
- **HTML 그대로 그리기**: 남은 두 곳(`WordIllust.tsx`)은 앱과 함께 빌드된 그림 파일만 그립니다(사용자 입력·AI 결과가 들어가지 않음). 그림 파일 34개에 스크립트·바깥 주소가 없는 것을 확인했습니다.
- **GitHub Actions**: 풀 리퀘스트로 도는 워크플로가 없어 바깥 기여자가 비밀값에 닿을 길이 없습니다. 빌드 워크플로는 읽기 권한만, 쓰기 권한은 배포(`deploy.yml`)와 손으로만 도는 지도 사진 워크플로뿐입니다. 비밀값은 서명 단계의 환경 변수로만 쓰이고 출력하지 않습니다.
  - 남은 것(전부터 있던 사용자 할 일): `main` 브랜치 보호와 Actions 버전 고정(S-07), 미리보기 서명 키 비밀번호를 Secrets 로(S-11).
- **새로 넣은 텔레그램 알림**: 봇 토큰은 텔레그램 주소로만 나가고 로그에 찍지 않습니다. 알림 글에는 계정·이메일이 없고, 글 앞부분 30자만(이메일·긴 숫자 모양은 가림) 들어갑니다.

## 5. 판정

**코드 쪽에서 출시를 막는 보안 항목은 남아 있지 않습니다.** 9/20 의 HIGH 3건은 모두 닫혔고, 새로 찾은 높음 2건(N-1·N-7)도 고쳤습니다.

**그러나 보안 게이트의 공식 판정은 아직 "통과"가 아닙니다.** 오늘 검사기 2.2.0 을 지금 코드에 다시 돌린 결과는 여전히 FAIL 이며, 이유는 셋입니다.

1. **검사기가 계속 표시하는 오탐** — 테스트가 시험용으로 그 자리에서 만드는 키의 머리글 문자열 1곳, 테스트의 가짜 저장 값 2곳, 워크플로의 캐시 이름·라이브러리 이름 3곳, 비우기만 하는 코드 2곳, 앱에 딸린 그림을 그리는 2곳, 크기 상한을 넘는 빌드 결과물.
   이것들은 프로젝트가 고칠 결함이 아니라 **HQ 가 예외로 등록**(소유자·이유·만료일)해야 사라집니다. 이 저장소는 보안 도구 폴더를 직접 고치지 않습니다.
2. **개발 도구의 치명 2 · 높음 1**(4절) — 완화는 적었지만, 게이트 규칙상 "업데이트 또는 승인된 완화"가 필요합니다. HQ 판단이 필요합니다.
3. **수동 확인 8칸** — 사람 검토자의 이름·날짜가 들어간 증거 파일이 있어야 하고, 그중 몇 가지(실제 계정 두 개, 실서버의 CORS·속도 제한, APK 풀어 보기)는 **서버를 배포한 뒤**에만 할 수 있습니다.

정리하면: "9/20 결과를 다시 보는 일"은 **끝났습니다.** "보안 게이트 통과"는 **HQ 의 예외 등록·개발 도구 판단·배포 뒤 수동 확인**이 남았습니다. 그 전에는 이 저장소 규칙대로 "출시 가능"이라고 말하지 않습니다.
